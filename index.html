Lesson 1

CSS :hover

The :hover pseudo-class applies styles when a pointing device, such as a mouse, moves over an element.

Color Change

The background color smoothly transitions from blue to violet on hover.

🚀
Hover to lift

Card Lift

The card moves upward using transform: translateY() creating a floating effect.

Image Scale

The image scales up using transform: scale(1.12) on hover.

Hover for underline →

Animated Underline

A pseudo-element underline animates its width from 0 to 100% on hover.

💡 Try it: Move your mouse over each demo above. The CSS :hover selector applies the styles only while the pointer is over the element.
CSS 
/* Button that changes color on hover */
.demo-button {
  background-color: #2563eb;
  transition: background-color 0.3s ease,
              transform 0.3s ease;
}

.demo-button:hover {
  background-color: #7c3aed;
  transform: translateY(-4px);
}
How it works: The transition property on the base selector tells the browser to animate the change smoothly. The :hover selector defines the destination values. When the pointer leaves, the values animate back.
Lesson 2

CSS :focus

The :focus pseudo-class applies styles when an element receives keyboard or other interactive focus.

Border Color Change

The border transitions from gray to blue when the input receives focus.

Focus Glow Ring

A box-shadow creates a soft glow ring around the input on focus.

Textarea Focus

A violet glow ring appears when the textarea is focused, great for forms.

Focus Outline

A visible outline appears when using Tab. Never remove focus indicators without a replacement!

💡 Try it: Click on any input above, or use the Tab key to navigate between them. Notice the visual change — that's :focus in action!
CSS 
/* Input with a glowing focus ring */
.demo-input {
  border: 2px solid #cbd5e1;
  outline: none;
  transition: border-color 0.3s ease,
              box-shadow 0.3s ease;
}

.demo-input:focus {
  border-color: #2563eb;
  box-shadow: 0 0 0 4px rgba(37, 99, 235, 0.2);
}
Accessibility tip: Focus indicators help keyboard users see where they are on the page. Always provide a visible focus style. If you set outline: none, replace it with a box-shadow or border change.
Lesson 3

CSS :active

The :active pseudo-class applies while an element is being activated — such as while a mouse button is held down on it.

Press Down Effect

The button physically pushes down with translateY(4px) and its shadow shrinks.

Background Darken

The background darkens momentarily while the button is pressed.

Color & Scale

The button shifts color and scales down slightly — a subtle "squish" effect.

💡 Try it: Press and hold each button above to see the :active state. Release to see it snap back. This is a temporary pressed state, not a permanent selected state.
CSS 
/* Button with a physical press effect */
.demo-button {
  box-shadow: 0 5px 0 #1d4ed8;
  transition: transform 0.1s ease,
              box-shadow 0.1s ease;
}

.demo-button:active {
  transform: translateY(4px);
  box-shadow: 0 1px 0 #1d4ed8;
}
Key insight: :active only applies while the element is being pressed. As soon as you release, the styles revert. Combined with fast transitions, this creates satisfying button feedback.
